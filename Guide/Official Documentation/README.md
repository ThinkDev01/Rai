# Official Documentation

**Customer-facing, publish-ready documents** — distinct from the internal `guide-*` and `dev-*` docs. These are written for users, the public, and legal/compliance, not for the build team.

| Doc | Purpose |
| --- | --- |
| `product-docs.md` | Public product guide — what Rai is and how to use it, written for customers |
| `release-notes.md` | What's new, most recent release first |
| `terms-of-service.md` | Terms of Service (India governing law) |
| `privacy-policy.md` | Privacy Policy (aligned to India's DPDP Act, 2023) |

## Before publishing — fill these placeholders

The legal docs use bracketed tokens that must be replaced before going live:

- `[LEGAL ENTITY NAME]` — the registered company/entity that owns Rai
- `support@rai.novetum.com` — official support/contact inbox (must be set up + monitored)
- `[product URL]` — production product domain
- `[effective date]` — the date the ToS/Privacy Policy take effect
- `[city, India]` — jurisdiction city for dispute resolution (ToS §14)
- `[name / designation]` — Grievance Officer (Privacy Policy §12)

> ⚠ The ToS and Privacy Policy are drafted to industry standard but are **not a substitute for legal review.** Have qualified counsel review both before publishing.
